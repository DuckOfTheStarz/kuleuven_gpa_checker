# KU Leuven GPA Checker
This program will allow you to take your existing KUL transcript (can be found on KU Loket)
and it will output data regarding your remaining credits. For instance, if your goal is to 
graduate Magna Cum Laude, this program will show you precisely your average credits necessary
to graduate with those honors, should that be feasible. 

# How to run the program
There are two files, but for the simplest execution, you ought to open your terminal, and run 
the command "python3 gpacalc_windowed.py". (python3 command may differ according to your OS
and python setup).
